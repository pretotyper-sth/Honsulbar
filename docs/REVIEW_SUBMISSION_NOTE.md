# 혼술바 심사 설명문

만 19세 이상 대상의 지역별 음성 소셜 서비스로 사전검수를 요청합니다. 토스 로그인 기반 성인 확인, 등록 사진의 사람 얼굴 자동 확인, 신고·차단 및 운영자 대응 기능을 제공합니다.

현재 버전에서는 음성을 녹음·임시 보관하거나 신고에 첨부하지 않습니다. 일반 음성 대화와 텍스트 신고를 제공합니다. 자세한 운영 방식은 첨부 정책의 현재 버전 안내를 참고해 주세요.

실시간 촬영 및 등록 사진과의 얼굴 대조 단계는 제공하지 않습니다. 도용 신고와 이의 제기는 운영자가 검토합니다.

검토 경로는 토스 로그인 → 프로필 사진 등록 및 저장 → 지역·호점 입장입니다. 가입 시 지급되는 2,000P로 시험할 수 있습니다.
