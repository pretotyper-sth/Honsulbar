### 배포 전 남은 순서

1. [ ] 무료 범위의 실제 HTTPS API 검증 환경 연결. 현재 기본 APK의 localhost API는 외부 배포 불가. 테스트 데이터와 운영 잔액을 구분하고, 중복 운영 스케줄러는 만들지 않음.
2. [ ] Google/Kakao 로그인→앱 복귀→PKCE 교환→공통 API 세션→재로그인까지 실제 확인. 취소·만료·앱 종료 복구 포함.
3. [ ] 공통 DB 백업 후 신규 identity 스키마 적용. 신규 회원 가입 경로·최근 로그인 기록, 명시적 계정 연결 전 자동 병합 금지, 가입 보너스·제재·탈퇴 후 재가입 검증. 앱인토스 회원 회귀 검사.

## 성공 판단과 운영 전환

- 로그인: 실제 공급자 토큰을 서버가 검증하고 동일 회원 세션이 발급되는지 확인.
- 결제: Google 무료 테스트 주문을 서버가 검증하고 원장에 한 번만 지급. 취소/대기는 미지급.
- 광고: 실제 SDK 완료 이벤트와 운영 서버 SSV를 구분. 단순 타이머·버튼 누름은 성공이 아님.
- 푸시: 실제 토큰/기기에 도착하고 클릭 이동·수신 거부·탈퇴 후 미발송 확인.
- DB: 가입 경로와 연결 회원/잔액 보존을 실제 데이터로 확인.
- 테스트 결과·실패 결과·최종 설정을 기록한 후 운영으로 전환. 현재는 아직 단일 승인으로 모든 기능을 켤 수 있는 완성 상태가 아님.
