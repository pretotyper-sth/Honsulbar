# 혼술바: 직접 확인할 마지막 순서

기준일: 2026-10-25. 자세한 절차는 LIVE_SAFETY_TEST_GUIDE.md에 있습니다. 아래 결과는 아직 사람이 확인하지 않은 항목이며, 체크되어 있다는 뜻이 아닙니다.

## 먼저 알아둘 상태

- 최신 운영 코드의 자동 테스트 74개 통과. 로그인·음성 기능 설정 활성화, 개발 로그인 비활성화 확인.
- 비로그인 관리자/음성 자료 접근, 익명 DB 음성 조회, 무인증 유지보수 실행 거절 확인. 공개 정책 HTML·PDF 접근 확인.
- 운영 데이터 정리·알림 재시도 수동 실행 성공. 예약 작업은 활성화돼 있지만 수정 후 예약 실행 성공은 별도 확인 대상이며 5분 내 실행을 보장하지 않습니다.
- 전화번호·통신판매업 신고번호는 모두 없음(사용자 재확인). 임시 번호를 넣지 않았습니다. 기능 시험과 실제 공개 유료 판매의 준비 완료는 구분합니다.

## 1. 관리자 로그인과 메일 (3분)

1. https://honsulbar-app.vercel.app/?admin=1 에서 pretotyper.sth@gmail.com 입력 → '이메일 링크로 로그인' → '로그인 링크 받기'.
2. 같은 기기에서 메일 링크를 엽니다. 스팸함도 확인합니다. 비밀번호는 몰라도 됩니다. 링크가 다른 사이트/localhost로 이동하거나 메일이 오지 않으면 그 주소 또는 오류 문구를 알려 주세요. 비밀번호나 로그인 링크 자체를 채팅에 붙이지 않습니다.
3. '새로고침' 후 문의·신고 목록과 라이브 연결 점검이 나오는지 봅니다. 토스 로그인 설정·신고 메일 설정·음성 DB·음성 보관이 모두 준비돼 있어야 합니다.
4. '운영자 시험 메일 보내기'를 한 번 누르고 실제 메일함에서 연동 시험 메일을 확인합니다. 화면의 업체 접수 성공만으로 수신 성공으로 체크하지 않습니다.

정상: 관리자 목록이 열리고 시험 메일이 도착합니다. 운영자 확인 공백에 따른 안전 점검은 실제 로그인·검토·새로고침으로 해제합니다. 접수된 신고가 있으면 실제 검토를 먼저 합니다.

## 2. 토스 로그인·얼굴 확인 (5분)

준비: 동의한 서로 다른 성인 토스 계정 A/B, 두 기기와 이어폰. 실제 이용자가 아닌 시험 참여자끼리 진행합니다. 운영 가입 포인트를 사용하고 이 단계에서 충전할 필요는 없습니다.

1. 최신 앱인토스 테스트 링크를 두 기기에서 엽니다. 최신 업로드는 저장소 Actions → Toss bundle의 성공 실행 로그에서도 확인할 수 있습니다.
2. A에서 토스 로그인 취소 후 재시도합니다. 취소 시 입장되지 않고, 재시도해 실제 토스 로그인하면 로비가 열려야 합니다.
3. 각자 본인 사진으로 등록·촬영 검사를 완료합니다. 밝은 장소에서 본인 사진이 승인되는지 봅니다. 시험에 동의한 B의 사진을 A가 등록해 촬영하면 사진 불일치로 거절돼야 합니다. 제3자 사진·미성년자는 시험에 사용하지 않습니다.
4. A/B 모두 별도 음성 처리 안내에 동의합니다. 체크하지 않은 상태로는 음성 입장이 진행되면 안 됩니다. 취소해도 로비·고객센터는 이용 가능해야 합니다.

기록: 기종/OS, 토스 버전, 성공·오류 문구. 얼굴 검사 실패가 반복되면 출시 전에 그 오류부터 수정해야 합니다.

## 3. 실제 음성 연결: 같은 와이파이와 서로 다른 통신망 (5분)

1. A/B를 같은 바에 입장시키고 양쪽 마이크·소리를 켭니다. 번갈아 '혼술바 안전 기능 시험입니다'를 말해 서로 실제로 듣는지 확인합니다.
2. 같은 와이파이에서 한 번 확인합니다. 이어 한 기기는 와이파이를 끄고 LTE/5G로 전환해 다시 연결·말하기를 확인합니다. 가능하면 서로 다른 통신사 모바일 데이터끼리도 확인합니다.
3. 1:1 대화를 쓰면 동의한 시험 참여자 C를 추가해, C에게 해당 대화가 들리지 않는지 확인합니다.

현재는 STUN을 통한 직접 연결만 설정돼 있고 TURN 중계는 없습니다. 특정 통신망에서 소리가 안 들리면 기종·네트워크·시각을 알려 주세요. 이 경우에는 TURN 서비스 연결이라는 개발 작업이 남으며, 시험을 통과한 것으로 처리하지 않습니다. 같은 와이파이 성공만으로 모바일 환경 전체의 연결성을 보장할 수 없습니다. 새 유료 중계 서비스 계약은 임의로 진행하지 않았습니다.

## 4. 신고 음성과 재접촉 차단 (5분)

1. B가 시험 문장을 5~10초 말한 직후 A가 B 프로필 → 신고를 엽니다. '상대 음성 최근 N초'가 보이고 N은 최대 20초여야 합니다.
2. 사유 '기타', 내용 '두 시험 계정의 안전 기능 시험'을 적고 음성 첨부를 선택해 접수합니다.
3. 둘 다 현재 바에 남되 서로 소리는 끊겨야 합니다. A가 나온 후 B가 있는 바 재입장은 거절돼야 합니다.
4. 관리자 → 새로고침 → 같은 사건 번호 → 음성 열람에서 B의 시험 문장이 재생되는지 봅니다. 실제 신고 알림 메일도 도착해야 합니다.
5. '확인 중'으로 바꾸고 시험 답변을 등록합니다. A의 알림·고객센터에서 답변을 확인합니다. 실제 계정에 영구 제재를 시험하지 않습니다.

정상: 신고 접수, 즉시 음성 제한, 관리자 재생, 메일 수신, 이용자 답변 확인이 모두 됩니다. 음성이 없어도 신고가 접수되는지도 새로운 시험 계정 쌍으로 확인합니다. 이미 신고한 쌍은 연결 제한 때문에 반복 음성 시험에 적합하지 않습니다.

## 5. 동의 철회와 종료 (2분)

1. 신고·차단 관계가 없는 시험 계정으로 바에서 설정 → 음성 안전 처리 동의 철회를 선택합니다.
2. 현재 방문·마이크·음성 연결이 종료되고, 다음 입장에 다시 동의가 필요해야 합니다.
3. 음소거·앱 백그라운드 전환 뒤 이전 음성이 계속 첨부되는 일이 없어야 합니다. 시험 중 작성한 신고는 관리자가 실제 결과를 적고 종료합니다.

## 기능 시험 뒤, 제출 전에 결정할 것

- 운영: 정책에 적은 매일 10:00~22:00 확인 및 모든 신고 24시간 내 검토를 실제로 할 수 있는지 확인합니다. 어렵다면 가능한 방식으로 정책·알림 체계를 함께 조정해야 합니다.
- 사업자: 전화번호·신고번호는 현재 보류합니다. 실제 공개 유료 판매 전 필요한 표시·신고 또는 적용되는 면제 근거를 확정해야 하며, 임시 값으로 완료 체크하지 않습니다.
- 국외 처리: Brevo 계정의 거래 메일 로그 보관 기간·데이터 처리 계약, Vercel 계정의 로그 보관 설정·재위탁 처리 범위를 확인합니다. 확인한 설정 화면이나 계약 문서의 개인정보 처리 부분을 제공하면 고지 문구를 맞춰 반영할 수 있습니다. API 키·로그인 정보는 보내지 않습니다. Google STUN 연결 정보 처리도 고지 범위에 포함합니다. 공개 문서의 일반 국가 안내만으로 실제 계정 계약까지 검증한 것은 아닙니다.
- 토스 심사: REVIEW_SUBMISSION_NOTE.md의 설명을 사용해 토스 로그인 인증 경로와 '최대 20초 신고 음성·운영자 검토, 상시 음성 AI 미적용' 방식을 정확히 공개합니다. 이 방식의 인정 여부를 확인하기 전 자동 음성 탐지 등 모든 체크 항목을 완료로 표시하지 않습니다.
- 결제·환불: 실제 결제를 열기 전 본인이 승인한 최소 거래로 충전·포인트 반영·취소/환불 내역의 일치를 확인합니다. 지금 시험만을 위해 결제를 할 필요는 없습니다. 시험하지 않았다면 결제·환불 완료로 체크하지 않습니다.

PDF: public/legal/honsulbar-monitoring-response-policy.pdf. 핵심 확인은 법인/담당 연락처, 운영 가능 시간·24시간 대응, 음성 최대 20초/7일 범위, 상시 음성 AI 미적용 사실입니다.
