# 음성 안전 처리 선택 근거

사용자 결정: 상시 자동 전사/외부 음성 AI 대신 신고 증거 제출·관리자 검토부터 완성한다.

커넥팅 공식 커뮤니티 가이드는 통화 녹음과 가명 처리·암호화 보관, 신고 음성의 보관을 공개한다. 문서 URL 경로가 오래된 공개 문서이므로 현재 앱의 실제 구현 전체를 검증했다는 뜻은 아니다.
https://yplabs.kr/2020/07/20/consent05-kr/

Riot 공식 안내는 음성 평가 및 신고 음성·전사 보관과 지역별 보유기간을 설명한다. Discord 공식 운영 교육 자료는 음성 미저장으로 증거 확보의 한계가 있음을 안내한다. 업계에 단일한 녹음 방식이 있는 것은 아니다.
https://support.riotgames.com/zh-my/valorant/penalties/comms-restrictions-and-audio-retention
https://pax.discord.com/community-moderation-safety

혼술바의 최소안은 동의한 참여자가 들은 상대 스트림의 최근 최대 20초를 기기에만 보관하고 신고 시 선택 제출하는 방식이다. 전체 대화 서버 업로드·상시 자동 전사·외부 전사 업체 비용을 추가하지 않는다. 서버 동의/관계 검사·암호화·관리자 열람 감사·7일 만료를 적용한다. 입장 시 설명과 상시 안내, 신고 화면의 선택으로 대화 중 반복 팝업을 피한다. 실제 웹뷰의 성능·안정성은 두 기기로 검증해야 한다.

기술적 한계: 이용자 기기가 제출하는 음성의 진위·화자·전체 맥락은 보장하지 않는다. P2P 서비스의 악의적인 변조 클라이언트가 서버 신호 제한을 우회해 기기에서 수집하는 것을 완전히 방지하는 DRM을 제공하지 않는다. 정상 앱의 수집·서버 제출·관리자 접근을 최소화하고 제재 판단에 한계를 반영한다.

프라이버시: 메모리에 잠깐 남기는 것도 음성 처리다. '녹음이 아니다'라고 표현하지 않는다. 대화에는 민감한 내용이 포함될 수 있어 별도 명시 동의·최소 보관·접근 제한·삭제가 필요하다. 동의만으로 적법성이 자동 확정되는 것으로 설명하지 않는다. 회사의 운영·관리 의무는 남는다.

앱인토스는 만 14세 이상 틴즈 사용자 노출을 공식 공지했으므로 플랫폼 전체를 19세 이상으로 가정하지 않는다. 기존 서버 토스 로그인 이름·생년월일 검사와 미성년자 거부를 유지한다.
https://toss.im/apps-in-toss/blog/update-26-06-11?slugOrId=discountspot

앱인토스의 만남·소개팅 체크리스트에는 불법 광고 탐지·대화 저장 항목이 있다. 이번 구현은 신고 증거 확보를 보완하며 자동 음성 내용 AI 탐지 전체를 구현한 것은 아니다. 이 차이를 숨기거나 승인 완료로 간주하지 않는다.
