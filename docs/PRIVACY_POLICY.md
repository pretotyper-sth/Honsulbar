# 혼술바 개인정보처리방침

시행일: 2026년 9월 24일

`상지컴퍼니 주식회사`(이하 “회사”)은 개인정보 보호법 등 관계 법령을 준수합니다. 본 방침은 혼술바 서비스에 적용됩니다.

## 1. 처리 목적

회사는 회원 식별과 로그인, 성인 이용자 확인, 프로필·지역·음료 취향 제공, 혼술바 입장과 음성 연결, 포인트·구독 결제, 알림 발송, 신고·차단·음소거 처리, 부정 이용 방지, 고객 문의와 분쟁 대응을 위해 개인정보를 처리합니다.

## 2. 처리하는 정보

- 필수(정식 토스 로그인 적용 시): 토스 이용자 식별자, 이름, 생년월일(만 19세 이상 여부 확인), 성인 인증·본인 확인 결과, 서비스 이용 기록, 신고·제재 기록. 다른 이용자에게는 이름 대신 앱에서 설정한 닉네임을 표시합니다.
- 선택: 프로필 사진, 성별, 자기소개, 지역·음료 취향
- 결제: 결제 상품, 결제 시각, 거래·환불 상태. 카드번호 등 결제수단 정보는 앱인토스 인앱 결제 시스템이 처리하며 회사가 직접 저장하지 않습니다.
- 자동 수집: 접속 시각, 기기·앱 정보, 오류 기록, 방 입장·퇴장 기록
- 신고 처리: 신고 내용, 신고 대상, 접수 시각, 조치 결과 및 필요한 최소 메타데이터
- 프로필 사진 확인: 입장을 위해 촬영한 임시 카메라 이미지. 현재 얼굴 존재 여부와 프로필 사진의 유사도를 기기에서 확인하며 촬영본을 서버에 전송하거나 저장하지 않습니다.

음성 원본은 저장하지 않습니다. 서비스는 음성 연결 상태와 안전 대응에 필요한 최소 메타데이터만 처리합니다.
촬영본은 확인 과정에서만 기기 메모리에 두고 확인이 끝나면 더 이상 사용하지 않습니다. 현재 사진 확인 결과는 해당 브라우저의 로컬 저장소에 보관되며 서버 기반 본인 인증을 대신하지 않습니다. 촬영에 동의하지 않으면 입장할 수 없습니다.
