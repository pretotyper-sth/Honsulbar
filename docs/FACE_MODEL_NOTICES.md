# 자동 사진 검사 모델 및 한계

이 기능은 사진별 운영자 승인 없이 작동하는 도용 방지 보조 검사입니다. 신분증 대조, 인증기관 본인인증, 실물 촬영의 완전한 보장을 제공하지 않습니다. 두 촬영본과 무작위 가까이/멀리 움직임을 비교하지만, 정교한 재생·합성·변조된 클라이언트 공격을 완전히 방지하지 못합니다. 공개 서비스 전 실제 기기에서 정상 통과·오탐·응답시간을 확인해야 합니다.

## 사용 소프트웨어

- Human 3.3.6: https://github.com/vladmandic/human (MIT). Node 배포판의 TensorFlow 로딩 대상을 공식 TensorFlow.js 4.22 WebAssembly 실행기로 변경했습니다. 분석은 별도 작업 스레드에서 실행합니다. 라이선스는 server/vendor/HUMAN-LICENSE에 포함합니다.
- BlazeFace: https://github.com/google-ai-edge/mediapipe (Apache-2.0). server/face-models/BLAZEFACE-LICENSE.
- FaceRes: https://github.com/HSE-asavchenko/HSE_FaceRec_tf (Apache-2.0). server/face-models/FACERES-LICENSE.
- LivenessNet: https://github.com/leokwu/livenessnet (Apache-2.0). server/face-models/LIVENESS-LICENSE.
- 모델 배포본: @vladmandic/human 3.3.6의 models 폴더. 재현 명령: npm run prepare:face-models.

서버가 모델을 직접 실행하므로 외부 얼굴 분석 API·SMS 계약은 추가하지 않았습니다. 서버 실행량에 따른 기존 호스팅 비용은 발생할 수 있습니다. 모델 기준값은 얼굴 감지 0.8, 얼굴 구조 0.9, 세 쌍의 얼굴 유사도 각각 0.62, 실물 촬영 가능성 0.5이며 인증 정확도나 심사 통과를 보장하는 수치가 아닙니다. 모델 내부의 연령·성별 출력은 이용자 연령 인증이나 프로필 성별 결정에 쓰지 않습니다.


## 2026-10-16 검증 흐름

1. 브라우저는 자체 배포한 BlazeFace 모델을 미리 로드·예열하고 기존 얼굴·일러스트 사전 검사를 유지합니다. 빠른 성공·실패도 검사 상태는 최소 1.5초 표시하며 오래 걸린 검사에 추가 대기를 붙이지 않습니다.
2. 동의한 사용자가 촬영하면 서버가 가까이/멀리 움직임을 지정합니다. 브라우저가 정상 얼굴 구도와 연속 움직임을 확인해 임시 사진 두 장을 전송합니다.
3. 서버는 FaceMesh 얼굴 구조, 얼굴 전체 노출, 정면 각도, 손과 얼굴의 겹침, 양쪽 눈과 입 영역의 명암·선명도, 촬영 가능성 모델을 검사합니다. 얼굴 구조 모델은 가려진 부분을 추정할 수 있으므로 구조 점수만으로 가림 여부를 확정하지 않습니다. 손 감지와 영상 품질 검사를 함께 적용하며 다른 물체·정교한 손가락 가림까지 모두 검출한다고 보장하지 않습니다.
4. FaceRes의 1,024차원 특징으로 등록 사진↔첫 촬영, 등록 사진↔둘째 촬영, 첫 촬영↔둘째 촬영을 모두 비교합니다. 눈·코 좌표나 피부색만으로 동일인 여부를 승인하지 않습니다. 특징·촬영본은 DB·파일·로그에 저장하지 않으며 처리 후 배열을 정리합니다.
5. 서버가 발급한 승인값은 회원·사진 원문에 묶이고 10분 동안 한 번만 저장에 사용할 수 있습니다. DB에서도 동의·만료·재사용을 검사합니다. 동의를 철회하거나 사진을 바꾸면 화면의 검증은 즉시 무효화되며 늦은 검사 응답도 무시합니다.
6. 모델 초기화 15초, 실행 45초 제한과 인스턴스당 최대 두 요청 대기를 적용합니다. 오류·혼잡·모델 준비 실패 시 통과시키지 않습니다.

추가 모델: MediaPipe FaceMesh/Hands, HandTrack. 공식 모델 설명: https://github.com/vladmandic/human/wiki/Models . 얼굴 특징 비교 설명: https://github.com/vladmandic/human/wiki/Embedding . 배포 가중치는 설치한 Human 3.3.6 패키지에서 복사합니다. 브라우저 사전 검사 가중치는 Google TF Hub BlazeFace v1입니다.

자동 검증: 공개 라이브러리의 예제 얼굴로 같은 인물의 배율 변화 통과, 다른 인물의 특징 불일치 거절, 절반을 검정색·피부색으로 가린 입력 거절을 확인했습니다. 실제 손가락 가림이나 여러 이용자의 정확도를 측정한 결과는 아닙니다. 초기 로컬 측정에서 단일 예제 분석은 CPU 약 3.3초에서 WASM 약 0.26초, 새 API의 세 이미지 전체 검사는 약 0.49초였습니다. 실제 기기·서버·사진에 따라 달라집니다.

출시 전 실제 기기에서 본인/타인 사진, 왼쪽·오른쪽 눈/코/입 가림, 안경, 어두운 조명, 마스크, 화면 재생을 점검합니다. 불확실한 입력은 재촬영으로 안내합니다. 이 구현은 공인 본인인증이나 인증된 위조 방지 서비스가 아닙니다.

## 2026-10-16 촬영 안내 개선

프로필 편집 시 서버 모델을 미리 준비하며 이 준비 요청은 사진을 보내거나 촬영 시도 횟수를 소비하지 않습니다. 촬영 화면 안에서 정면 촬영 → 거리 조절 → 얼굴 비교 단계를 안내합니다. 거리 조절은 정면을 유지한 채 얼굴과 카메라의 거리를 바꾸는 동작이며, 감지한 크기 변화로 진행도를 표시합니다. 반대 방향·과도한 이동·일시적 얼굴 감지 실패는 화면 안에서 교정 안내를 제공합니다. 정면 촬영은 안정된 연속 표본을 요구하고, 일시적인 감지 누락은 즉시 실패시키지 않습니다. 서버 얼굴 비교·가림 검사와 승인값 검증은 유지합니다.

준비·서버 비교 중에는 경과 시간을 표시하고, 검사 중단·동의 철회·촬영 화면 종료 시 클라이언트 요청을 취소합니다. 이미 서버에 도착한 검사는 처리 제한 안에서 종료될 수 있으나 그 응답으로 취소된 화면을 승인하지 않습니다. 준비 요청은 20초, 비교 요청은 50초 내 응답하지 않으면 재시도를 안내합니다. 촬영 시도마다 독립된 임시 캔버스를 사용합니다.
