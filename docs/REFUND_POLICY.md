# 혼술바 결제·환불 정책

시행일: `[서비스 출시일 입력]`

1. 포인트와 구독의 가격·기간·혜택은 결제 전에 표시합니다.
2. 미사용 포인트, 중복 결제, 결제 오류는 확인 후 환불 또는 복구합니다.
3. 이용자가 포인트를 사용했거나 구독 혜택을 이용한 경우 환불 가능 여부와 금액은 결제대행사 정책 및 관계 법령에 따릅니다.
4. 자동 결제 구독은 다음 결제일 전 해지할 수 있으며, 해지 후에도 이미 결제된 기간의 잔여 이용은 결제 화면에 표시된 조건에 따릅니다.
5. 환불·분쟁 문의는 `pretotyper.sth@gmail.com`으로 접수하며, 영업일 3일 이내 1차 답변을 제공합니다.
6. 부정 결제·반복 환불 악용이 확인되면 서비스 이용을 제한할 수 있습니다.

결제 사업자: `[결제대행사 입력]`  
사업자명: `[법인명 또는 사업자명 입력]`
