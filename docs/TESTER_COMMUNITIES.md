## 추가 조사: 더 큰 해외 그룹 (2026-11-01)

외부 집계의 회원 수이며 실시간 Reddit 접속자 수가 아니다. 집계 시점별 차이가 있다. 공개 그룹 피드에서 최근 모집 글도 별도로 확인했다.

- [AndroidClosedTesting](https://www.reddit.com/r/AndroidClosedTesting/): Google Play 비공개 테스트에 가장 직접적인 후보. 외부 집계 약 4.8만 명(2026-10-31 기준 글).
- [AndroidAppTesters](https://www.reddit.com/r/AndroidAppTesters/): 무료 맞테스트 중심. 외부 집계 약 1.4만 명(2026-09-30 갱신). 해당 그룹은 직접 APK 공유를 금지하고 공식 스토어 링크를 요구한다.
- [TestMyApp](https://www.reddit.com/r/TestMyApp/): 모바일 앱 테스트·사용성 피드백. 외부 집계 약 3.3만 명.
- [alphaandbetausers](https://www.reddit.com/r/alphaandbetausers/): 앱·웹 초기 이용자 모집, 외부 집계 약 5.1만 명. Android 14일 테스트 전용은 아니다.
- [betatests](https://www.reddit.com/r/betatests/): 베타 테스트 모집, 외부 집계 약 1.9만 명.
- [TestersCommunity](https://www.reddit.com/r/TestersCommunity/): Android 12명·14일 맞테스트 모집 글과 실제 피드백·스크린샷 규칙 확인. 회원 수는 확정하지 않음.
- [디스콰이엇](https://disquiet.io/): 한국어 서비스의 소개·초기 이용자 피드백 채널. 비공개 테스트 인원을 채워 주는 전용 그룹은 아니며 현재 회원 수는 확정하지 않음.

회원 규모 출처: [LaunchList, 2026-10-31](https://getlaunchlist.com/blog/how-to-find-beta-testers), [GummySearch AndroidAppTesters, 2026-09-30](https://gummysearch.com/r/AndroidAppTesters/).

현재 APK는 PC 로컬 서버에 의존하므로 이 그룹들에 지금 배포본으로 게시하지 않는다. 우선 가입·규칙 확인·참여 의향 수집을 진행하고, 공용 테스트 환경과 Play 테스트 링크를 준비한 뒤 실제 테스트를 시작한다. 한국어 대화 UX 피드백은 한국어 가능 성인 테스터를 별도로 확보한다.
