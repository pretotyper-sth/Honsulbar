# 혼술바 데이터 보유·자동 삭제 기준

## 적용 기준

- 음성 원본은 저장하지 않습니다.
- 회원 탈퇴 요청 시 서비스 제공용 프로필과 활성 세션을 즉시 비활성화하고 30일 이내 영구 삭제합니다. 법정 보존 대상은 분리 보관 후 기간 만료 시 삭제합니다.
- 방 입장·퇴장·음성 연결 메타데이터: 생성 후 30일
- 알림 발송·읽음 기록: 생성 후 90일
- 고객 문의·신고 원문과 처리 기록: 사건 종결 후 3년
- 결제·환불 기록: 전자상거래 등 관계 법령상 보존 기간
- 보안·접속 로그: 생성 후 3개월

## 삭제 작업

운영 DB에는 각 레코드에 `expires_at`을 저장합니다. 매일 1회 스케줄 작업이 `expires_at < now()`인 데이터를 삭제하고 삭제 건수와 실패 건수를 운영 로그에 남깁니다. 법정 보존 대상은 `retention_reason`과 `retention_until`을 별도로 기록하여 일반 삭제 대상에서 제외합니다.

## 현재 저장소 상태

현재 혼술바 저장소에는 Supabase, Prisma, 서버 API 또는 운영 DB 연결이 없습니다. 문의·알림·방 상태는 브라우저 메모리에서 동작하는 프로토타입입니다. 따라서 실제 자동 삭제는 운영 DB를 선택하고 연결한 뒤 이 기준으로 서버 작업을 구현해야 합니다.
